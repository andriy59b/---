# UkraineCraft — Соняшниківськ, 1996

Оригінальна гра з відкритим світом для PSP у стилі «Україна 90-х»: піксельна
низькополігональна графіка, місто з панельками й приватним сектором, машини тих часів,
трафік, сюжет із кат-сценами та озвученими персонажами, радіо в машині.
Написана на C з PSPSDK (`sceGu`/`sceGum`/`sceAudio`). Усі текстури, моделі, шрифт, музика,
звуки й голоси генеруються в коді — сторонніх ресурсів немає.

## Сюжет (розділ 1)

Літо 1996-го. Андрій повертається з армії в рідний Соняшниківськ. Завод стоїть, зарплату
не платять, на ринку продають усе, а районом заправляє Кабан.

Вступ і п'ять місій: брат Тарас у гаражах, його «Ластівка», ринок і тітка Галя, пакунок
до ларька на час, погоня чорного «Гелендера» і зустріч із Кабаном. Між місіями — кат-сцени
з планами камери, «через плече», жестами, субтитрами й голосами. Усі персонажі й події вигадані.

## Що в грі

- **Графіка:** піксельні текстури 64×64 (фасади панельок із фіранками й білизною на балконах,
  шифер, паркани, вивіски «ПИВО», «КАВА», «ЦИГАРКИ»), увечері світяться вікна, фари й ліхтарі
- **Місто:** дороги з бордюрами, тротуарами й зебрами, п'яти- й дев'ятиповерхівки, хати з
  двосхилими дахами й городами, гаражі, ринок, ларьки, парки, школа; за містом — поля
  соняшнику й пшениці, лісосмуги, траса з відбійниками. Ліхтарі стоять на тротуарах, а не на дорозі
- **Машини** (вигадані назви, без логотипів): «Кайзер 525» (баварський седан), «Ластівка 09»,
  «Класика 07», «Пантера Гранд» (американський джип), «Гелендер G» (німецький «кубик»), «Поле 4x4»
- **Фізика авто:** шини з кутами ковзання, перерозподіл ваги, коробка передач і оберти, ручник
  і занос, крен і клювання кузова, бордюри, удари з імпульсами (машини відштовхуються й крутяться)
- **Трафік:** їздить своїми смугами, повертає по дугах, гальмує перед пішоходами й сигналить
- **Персонажі:** скелет із 15 кісток; ходьба й біг прив'язані до швидкості (ноги не ковзають),
  дихання в спокої, підготовка до стрибка й присідання при приземленні, нахил у поворотах,
  жести, поза водія, падіння від удару машиною; рухи з інерцією
- **Посадка в машину:** Андрій підходить до дверей, відчиняє, сідає, зачиняє; можна «позичити»
  машину з трафіку — водій утече
- **Голоси:** для кожного персонажа синтезується мовлення зі своєю висотою й тембром за текстом
  репліки, губи рухаються в такт; можна підкласти власні записи (див. нижче)
- **Радіо:** оригінальна музика в стилі 90-х на «Радіо Соняшник FM» і «Шансон-хвилі»

> Справжні пісні 90-х, назви й логотипи реальних машин захищені правами, тому в грі
> використано лише оригінальну музику та вигадані моделі.

## Керування

**Пішки** (камера за спиною)

| Кнопка | Дія |
|---|---|
| Аналог | Рух (злегка — крок, повністю — біг) |
| ✕ (тримати) | Спринт |
| □ | Стрибок |
| △ | Сісти в машину |
| L / R | Повернути камеру |
| ↑ / ↓ | Нахил камери |
| SELECT | Вид від першої особи |
| START | Пауза |

**За кермом**

| Кнопка | Дія |
|---|---|
| ✕ або аналог вгору | Газ |
| □ або аналог вниз | Гальмо / задній хід |
| Аналог вліво-вправо | Кермо |
| ○ | Ручник (занос) |
| ↑ | Сигнал |
| ← / → | Радіостанція |
| L + R | Дивитися назад |
| △ | Вийти (на малій швидкості) |
| SELECT | Камера з капота |

У кат-сценах: ✕ — наступна репліка, START — пропустити сцену.

## Збирання і запуск

```sh
make -C psp                 # psp/EBOOT.PBP (PSPDEV toolchain)
make -C psp/tests check     # тести на ПК: фізика, анімація, місто, сюжет, звук
make -C psp/tools && psp/tools/preview out/   # картинки міста, машин і сцен на ПК
```

GitHub Actions збирає EBOOT на кожен push (артефакт `ukrainecraft-psp`).
Поклади `EBOOT.PBP` у `PSP/GAME/UkraineCraft/`. Збереження — у `ukrainecraft_save/`.
Гра використовує розширену пам'ять (PSP-2000 і новіші, PPSSPP).

