# Kubik — воксельна пісочниця для PSP

Оригінальна гра-пісочниця з блоків для PSP, написана на C з PSPSDK (`sceGu`/`sceGum`).
Усі текстури генеруються процедурно в коді, сторонніх ресурсів немає.

## Можливості

- Світ 64×32×64 блоки: процедурний рельєф, вода, пляжі, дерева
- 10 типів блоків: трава, земля, камінь, пісок, дерево, листя, дошки, скло, цегла, вода
- Ламання та ставлення блоків, підсвічування блоку під прицілом
- Фізика гравця: гравітація, стрибки, колізії, плавання; режим польоту
- Прозорі листя/скло (alpha test) і напівпрозора вода (blending), туман
- Збереження світу в `world.dat` поруч з EBOOT при виході

## Керування

| Кнопка | Дія |
|---|---|
| Аналог | Рух |
| △ / ✕ | Дивитися вгору / вниз |
| □ / ○ | Поворот вліво / вправо |
| L | Зламати блок |
| R | Поставити блок |
| ← / → | Вибір блоку на панелі |
| ↑ | Стрибок (у польоті — вгору) |
| ↓ | У польоті — вниз |
| SELECT | Увімкнути/вимкнути політ |
| START | Зберегти й вийти |

## Збирання

Потрібен [PSPDEV toolchain](https://pspdev.github.io/):

```sh
make -C psp          # створює psp/EBOOT.PBP
```

Або через Docker:

```sh
docker run --rm -v "$PWD":/src -w /src/psp pspdev/pspdev:latest sh -c "apk add make && make"
```

GitHub Actions (`.github/workflows/psp.yml`) збирає EBOOT на кожен push і публікує
його як артефакт `kubik-psp`.

Тести платформонезалежної логіки (світ, raycast, фізика, меші, збереження) запускаються на ПК:

```sh
make -C psp/tests check
```

## Запуск

- **PSP з кастомною прошивкою:** скопіюйте `EBOOT.PBP` у `ms0:/PSP/GAME/Kubik/EBOOT.PBP`.
- **Емулятор PPSSPP:** відкрийте `EBOOT.PBP` через *Load…*.

## Структура

```
psp/src/world.c     дані світу, генерація, raycast, фізика, збереження
psp/src/mesh.c      побудова мешів чанків 16×16 з відсіканням прихованих граней
psp/src/textures.c  процедурний атлас текстур 64×64
psp/src/main.c      ініціалізація GU, ввід, рендер, HUD
psp/tests/          тести для ПК
```

## Ідеї на майбутнє

- Back-face culling і стрічки трикутників для швидшого рендеру
- Більший світ із потоковим завантаженням чанків
- Освітлення / ambient occlusion, день і ніч
- Звук, меню, кілька слотів збереження
