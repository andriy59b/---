# Kubik — воксельна пісочниця для PSP

Оригінальна гра-пісочниця з блоків для PSP, написана на C з PSPSDK (`sceGu`/`sceGum`).
Усі текстури, шрифт і світ генеруються процедурно в коді, сторонніх ресурсів немає.

## Можливості

- **Нескінченний світ:** чанки 16×64×16 підвантажуються навколо гравця, змінені чанки
  зберігаються окремими файлами
- **Біоми:** рівнини, ліс, пустеля, сніжна тайга, гори, океан, пляжі
- **Печери й руди:** тунелі з 3D-шуму; вугілля, залізо, золото, кристали (що глибше, то рідше)
- **Рослинність:** дуб, береза, ялина, кактуси, висока трава, квіти
- **29 типів блоків**, текстури 32×32
- **Освітлення:** м'які тіні (ambient occlusion), небесне світло, темні печери
- **День і ніч:** градієнт неба, сонце, місяць, хмари, що пливуть, захід сонця
- **Блок у руці** з анімацією, рамка навколо блоку під прицілом
- **Меню паузи:** дальність прорисовки (2–8 чанків), чутливість огляду, цикл дня, час, інформація (FPS, координати, біом)
- **Вибір блоків:** сітка з усіма блоками, панель на 9 слотів
- Політ (подвійне натискання ↑), плавання, автозбереження кожні 3 хвилини

## Керування

| Кнопка | Дія |
|---|---|
| Аналог | Рух |
| △ / ✕ | Дивитися вгору / вниз |
| □ / ○ | Поворот вліво / вправо |
| L | Зламати блок |
| R | Поставити блок |
| ← / → | Вибір слоту на панелі |
| ↑ | Стрибок; **двічі** — увімкнути/вимкнути політ; у польоті — вгору |
| ↓ | У польоті — вниз |
| SELECT | Вибір блоків (✕ — покласти в слот, L/R — змінити слот, ○ — закрити) |
| START | Меню паузи (зберегти й вийти — там) |

## Збирання

Потрібен [PSPDEV toolchain](https://pspdev.github.io/):

```sh
make -C psp          # створює psp/EBOOT.PBP
```

Або через Docker:

```sh
docker run --rm -v "$PWD":/src -w /src/psp pspdev/pspdev:latest sh -c "apk add make && make"
```

GitHub Actions (`.github/workflows/psp.yml`) збирає EBOOT на кожен push і публікує
його як артефакт `kubik-psp`.

Тести платформонезалежної логіки (генерація, світ, меші, raycast, фізика, збереження):

```sh
make -C psp/tests check
```

## Запуск

- **PSP з кастомною прошивкою:** скопіюйте `EBOOT.PBP` у `ms0:/PSP/GAME/Kubik/EBOOT.PBP`.
- **PPSSPP:** відкрийте `EBOOT.PBP` через *Load…*.

Світ зберігається в папці `kubik_world/` поруч з EBOOT. Щоб почати новий світ — видаліть її.
Гра вмикає розширену пам'ять (PSP-2000 і новіші, PPSSPP). На PSP-1000 дальність
прорисовки автоматично зменшиться, якщо забракне пам'яті.

## Структура

```
psp/src/gen.c       генерація: висоти, біоми, печери, руди, дерева, рослини
psp/src/world.c     чанки, стрімінг, збереження, raycast, фізика гравця
psp/src/mesh.c      меші чанків: відсікання граней, AO, світло, 16-бітні вершини
psp/src/textures.c  процедурний атлас 256×256 (тайли 32×32) і шрифт 5×7
psp/src/render.c    sceGu: небо, світ, вода, хмари, ніч, блок у руці, 2D
psp/src/main.c      ігровий цикл, ввід, меню, інвентар, день/ніч, збереження
psp/tests/          тести для ПК
```
