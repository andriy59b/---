# UkraineCraft — Соняшниківськ, 1996

Оригінальна відкрита гра для PSP у стилі «Україна 90-х»: воксельне місто, яке можна
ламати й будувати, авто, трафік, сюжетні місії, радіо в машині.
Написана на C з PSPSDK (`sceGu`/`sceGum`/`sceAudio`). Усі текстури, шрифт, світ, музика
і звуки генеруються в коді — сторонніх ресурсів немає.

## Сюжет

Літо 1996-го. Андрій повертається з армії в рідне місто Соняшниківськ. Завод стоїть,
зарплату не платять, на ринку продають усе, а районом заправляє Кабан.

**Розділ 1** — п'ять місій: знайти брата Тараса в гаражах, сісти за кермо його «Ластівки»,
доставити пакунок тітки Галі до ларька на час, відірватися від чорної машини людей
Кабана і зустрітися з самим Кабаном. Після цього — вільна гра.

Усі персонажі, місто й події вигадані.

## Можливості

- **Місто Соняшниківськ:** сітка вулиць з розміткою й ліхтарями, п'яти- та
  дев'ятиповерхівки, гаражі, ринок з ларьками, приватний сектор з хатами й городами,
  парки з березами, школа; навколо — поля соняшнику й пшениці, траса за місто
- **Авто:** будь-яку машину можна взяти (↓), аркадна фізика, сигнал, вигляд назад
- **Трафік:** машини їздять своїми смугами, повертають на перехрестях, гальмують
  перед пішоходами й сигналять
- **Камера від першої і третьої особи** (SELECT), модель Андрія в спортивному костюмі
- **Радіо в машині:** «Радіо Соняшник FM 103.5» і «Шансон-хвиля 88.2» з оригінальними
  треками в стилі 90-х (дискотека, естрада, вальс, гаражний рок), перемикання ←/→
- **Звуки:** двигун, сигнал, двері, удари, кроки, блоки, джингли місій
- **Заставка, головне меню, налаштування** (дальність, чутливість, гучність музики й звуків,
  день/ніч), українська мова інтерфейсу
- Усе з попередніх версій: нескінченний світ із біомами, печерами й рудами, день і ніч,
  хмари, будівництво з 44 типів блоків, збереження

> Пісні справжніх українських радіостанцій 90-х захищені авторським правом, тому в грі
> звучить лише оригінальна музика, написана спеціально для неї.

## Керування

**Пішки**

| Кнопка | Дія |
|---|---|
| Аналог | Рух |
| △ ✕ □ ○ | Огляд |
| L / R | Зламати / поставити блок |
| ← / → | Слот на панелі блоків |
| ↑ | Стрибок (двічі — політ) |
| ↓ | Сісти в машину поруч |
| SELECT | Перша / третя особа |
| START | Пауза (блоки, налаштування, збереження) |

**За кермом**

| Кнопка | Дія |
|---|---|
| ✕ або аналог вгору | Газ |
| □ або аналог вниз | Гальмо / задній хід |
| Аналог вліво-вправо або L/R | Кермо |
| ↑ | Сигнал |
| ← / → | Радіостанція |
| △ | Дивитися назад |
| ↓ | Вийти (на малій швидкості) |
| SELECT | Ближня / дальня камера |

## Збирання

```sh
make -C psp                  # psp/EBOOT.PBP (потрібен PSPDEV toolchain)
make -C psp/tests check      # тести логіки на ПК
```

GitHub Actions збирає EBOOT на кожен push (артефакт `ukrainecraft-psp`).

## Запуск

Покладіть `EBOOT.PBP` у `PSP/GAME/UkraineCraft/EBOOT.PBP` (на PSP з кастомною прошивкою
або в PPSSPP). Збереження — у папці `ukrainecraft_world/` поруч.

## Структура

```
psp/src/main.c      режими гри, ввід, камери, стрімінг чанків, збереження
psp/src/hud.c       заставка, меню, діалоги, HUD
psp/src/render.c    sceGu: світ, небо, хмари, машини, герой, маркери, текст
psp/src/story.c     сюжет: вступ, місії, діалоги
psp/src/vehicle.c   фізика авто, трафік, переслідувач
psp/src/town.c      генерація міста й сюжетні точки
psp/src/gen.c       рельєф, біоми, печери, руди, дерева, поля
psp/src/world.c     чанки, raycast, фізика гравця, збереження
psp/src/mesh.c      меші чанків (AO, світло)
psp/src/textures.c  процедурні текстури та шрифт з кирилицею
psp/src/synth.c     синтезатор: музика й звуки
psp/src/audio.c     аудіопотік PSP
psp/tests/          тести для ПК
```
